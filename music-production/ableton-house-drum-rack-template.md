# Stage 1 — Drum rack

**Part of:** [Music Production Process](ableton-house-production-workflow.md)  

Build a five-pad house rack — kick, clap, closed hat, open hat, percussion — labeled and saved as `House Drums.adg` on **Drums**. One-time setup so you open the template and play, not hunt samples.

## Examples
- Load an existing kit (e.g. `808 Core Kit.adg`), swap the clap, save as `House Drums.adg`
- Insert Drum Rack, assign five samples (kick, clap, hats, percussion)
- Keep the kit as-is if you'd release with those sounds

## Done when
- [ ] **Drums** track (or your fixed name), rack loaded and ready
- [ ] Kick, clap/snare, closed hat, open hat each on their own pad with a sound you would use on a finished track
- [ ] At least one percussion pad with a loaded sample (shaker, rim, ride, etc.)
- [ ] Pads labeled at a glance on the rack
- [ ] Preset saved (e.g. `House Drums.adg`) whenever you changed anything from factory defaults
- [ ] 4-on-the-floor kick + offbeat hat programmable in under 2 minutes on a fresh template open

## Build (pick one path)

**Start from existing kit**
1. New MIDI track → load an existing drum kit preset (`.adg` from Ableton's browser or your library)
2. Audition each pad; swap any pad that needs a better sample, or keep the kit as-is when every pad already works
3. Swap house-typical elements (tighter clap, crisp hats) from your sample folder where needed
4. Rename pads; rename track **Drums**
5. Save rack as **House Drums.adg** in your user library

**Build from scratch**
1. New MIDI track → insert Drum Rack
2. One sample per pad: kick, clap, closed hat, open hat, percussion
3. Balance kick and clap levels with headroom on the rack output
4. Rename pads; rename track **Drums**
5. Save rack as **House Drums.adg**

**Hybrid**
1. Load an existing kit preset (`.adg`)
2. Replace kick and clap only (or kick only) from go-to samples
3. Save as **House Drums.adg**

## House defaults (starting point)

| Pad role | Starting note (adjust to taste) |
|----------|----------------------------------|
| Kick | C1 |
| Clap / snare | D1 |
| Closed hat | F#1 |
| Open hat | G#1 |
| Percussion | A1 or adjacent |

---

## Appendix — Add samples to the rack

1. New MIDI track → browser **Drums → Drum Rack** (the device, not a `.adg` kit) → drag onto the track. Or load an existing kit `.adg` instead.
2. Drag one-shots from the browser onto the pad grid — empty slot creates a pad; dropping on an existing pad replaces that sample
3. To replace without dragging: click the pad → **Hot-Swap Sample** → browse the browser; each click loads that file on the pad so you can hear it before you pick one
4. Click a pad and hit its MIDI note to audition; adjust **Vol** on the pad if the level jumps
