# Music Production Process

**DAW:** Ableton Live (Arrangement view)  
**Genre:** House  
**Time:** about 1 hour, twice per week  
**Goal:** Full tracks (5–7 minutes)

---

## Overview

**Goal:** Finish full house tracks on 2 hours/week — not more loops abandoned at 4–8 bars. You stall after solid drums because you don't know what section comes next, then save, start fresh, or mix instead of extend. This process separates writing, arranging, and mixing into dedicated modes so each hour has one job: template/prep removes setup from creative time; Mode A produces an 8-bar loop with harmony fixed early; Mode B adds one section per hour against a written map; Mode C and export close the loop so "done" is a file, not a feeling.

**Strengths:** drums, mixing  
**Bottlenecks:** arrangement, chords & bass  
**Typical stall:** 4–8 bar loop, no clear sections

---

## Stage 1 — Prep (admin, separate from writing)

**When:** Every 2–3 weeks, or the first 15 minutes of one session — not while arranging.

**Goal:** Front-load the boring work so your 1-hour blocks go straight to music. You start blank and lose arrangement flow hunting sounds and building racks — with limited time, every minute choosing a kick is a minute not spent on your actual bottleneck. A house template, a small go-to sample folder, and archiving finished work mean you open Ableton and play within five minutes, and only 1–3 active projects compete for attention.

| Phase | What |
|-------|------|
| Template | House `.als` with [drum rack](ableton-house-drum-rack-template.md), [bass rack](ableton-house-bass-rack-template.md), [stab](ableton-house-stab-template.md), [pad](ableton-house-pad-template.md) ([Analog protocol](ableton-analog-pad-template.md)), return tracks, bus routing, track colors |
| Sample folder | 10–20 go-to kicks, hats, percussion, one-shots |
| Archive | Move finished or abandoned projects out of "active" |

**Checkpoint:** Template opens in under 30 seconds. Never start from a fully blank set.

---

## Stage 2 — Session start (about 5 min, every hour)

**Goal:** Declare what this hour is for before touching the timeline. You currently blend loop-writing and arranging in one session, and wet tweaking feels productive without adding sections — untenable at 2 hours/week. Picking tempo + key and one mode (loop, arrange, or mix) means you leave knowing what progressed; recording the mode lets you pick up days later without re-listening for twenty minutes.

1. Open **template** (not blank set)
2. Pick **tempo + key** (both, every session)
3. Pick **one mode** for this hour:

| Mode | Purpose |
|------|---------|
| **A — Loop** | Write only; no arrangement |
| **B — Arrange** | Extend only; no new instruments |
| **C — Mix** | Levels, bus glue, reverb/delay only |

**Checkpoint:** Mode recorded in project name or a note clip (e.g. `MODE: Arrange`).

---

## Stage 3 — Loop (creative, Mode A)

**Goal:** End with an 8-bar loop — drums, chord stabs/pads, bass — that's worth arranging, not harmony you'll tolerate once it's on a timeline. You stall at 4–8 bars with repetitive chords you can't fix later; Mode A fixes that while the loop is still small: cap at 8 bars, apply the chord rule once, save a named groove, and don't arrange yet. Next session's Mode B has real material to extend.

### Phases

1. Start with **drums** or **keys** (either is fine)
2. Add the other — bass/chords via live MIDI and piano roll
3. Stop at **8 bars max** if progression still feels like "4+ chords but repetitive"

### Chord rule (5 min max, before leaving Mode A)

Change **one** of:

- Chord rhythm (stab length / syncopation)
- One chord in the loop
- Bass pattern against the same chords

Do not add more layers to fix harmony.

**Checkpoint:** 8-bar loop; named (e.g. locator `Main Groove`). Save. **Do not arrange in Mode A.**

---

## Stage 4 — Arrangement (creative, Mode B)

**Goal:** Add one section per hour until you have a 5–7 minute track. Your bottleneck isn't technique — you already duplicate loops and copy 8-bar blocks — it's not knowing what comes next, which leads to saving or starting over. A 3-minute section list answers that before you touch clips; no new sounds or wet processing keeps the hour on structure; if harmony breaks, 15 minutes of Mode A on the same project beats a blank set. Five arrange hours ≈ one finished structure at your pace.

### Before the timeline (3 min, admin)

Write a **section list**. Example:

`Intro → Groove → Break → Drop/Groove → Outro`

Mandatory for every Mode B session.

### Phases

1. **Duplicate loop** → mute/unmute layers per section
2. **Copy 8 bars** → change **one** element (hats, bass, chord stab, drum fill)

### Rules

- No new plugins or sounds
- No reverb/delay/bus work (that's Mode C)
- If stuck on "what's next," follow the **section list**, not feeling
- If stuck on harmony: don't start a new project — 15 min Mode A chord/bass fix on the same project, then back to Mode B

### Checkpoints

- Each new section = **save** + locator/name (`Break`, `Drop`, etc.)
- One hour = **one section added or extended**, not a full track

---

## Stage 5 — Mix (Mode C)

**Goal:** Get a rough mix you trust on headphones and monitors so you can hear whether the arrangement works — not whether reverb is hiding a missing drop. Mixing is a strength, but making tracks wet during writing is how you avoid adding sections; Mode C keeps that skill pointed at finishing. Fixed order (levels → bus → space → dual check) confirms structure is done and points you at export.

### Phases

1. Levels
2. Bus glue
3. Reverb / delay
4. Check on **headphones and monitors**

**Checkpoint:** Rough mix trustworthy enough to judge arrangement decisions.

---

## Stage 6 — Finish (admin)

**Goal:** Export a WAV and archive the project so "full track" is a file on disk, not an Ableton set you reopen forever. You save diligently but lack a hard endpoint — export breaks the loop-only cycle, archiving frees mental space, and holding 1–3 active projects forces finish-or-kill before the next idea.

1. Export WAV
2. Archive project
3. Keep **1–3** active projects max

**Checkpoint:** Exported file = done; project archived.

---

## Weekly rhythm (2 hours)

**Goal:** Make two hours compound on the same project: loop in week 1, one section per arrange hour in weeks 2–4, mix and export in week 5. You can't add hours with a small child — only clarity per hour — so don't arrange a loop that isn't ready, and don't loop-write when the track needs sections.

| Session | Suggested mode |
|---------|----------------|
| Hour 1 | **A** if loop is under 8 bars or chords feel wrong; **B** if loop is solid |
| Hour 2 | Opposite of hour 1, or **B** twice if close to full arrangement |

**Prep weeks:** Steal 15 min from one session, or use a third micro-block when possible.
