# Stage 1 — Bass rack

**Part of:** [Music Production Process](ableton-house-production-workflow.md)  

Build **one** house bass sound on **Bass** — a synth or rack with settings locked in. Save as `House Bass.adg`. One-time setup so Mode A spends time on the bass pattern against the chords, not browsing bass presets.

## Examples
- **Analog**, **Wavetable**, or **Operator** with a simple mono sub/low-mid patch → save as `House Bass.adg`
- Existing bass Instrument Rack with effects removed or disabled
- Two-chain rack: clean sub plus quiet mid bass layer, both controlled from one MIDI clip

## Done when
- [ ] **Bass** track (or your fixed name), preset loaded and ready
- [ ] Plays a short one-note MIDI pattern without opening devices
- [ ] Mono or near-mono in the low end
- [ ] Clear fundamental under **Drums** without clipping the master
- [ ] Works against **Pad** and **Stab** without forcing a new chord choice
- [ ] No reverb or delay on the device (space is Mode C)
- [ ] Preset saved whenever you changed anything from factory defaults

## Build (pick one path)

**Synth bass (default)**
1. New MIDI track → synth (e.g. **Analog**, **Wavetable**, or **Operator**)
2. Set one oscillator or simple two-oscillator blend; keep the low end focused
3. Use a fast attack, short-to-medium decay, and controlled release so notes stop cleanly
4. Keep the patch mono or near-mono; no device reverb or delay
5. Balance while **Drums** plays, then check against **Pad** and **Stab**
6. Save as **House Bass.adg**; rename track **Bass**; add to template

**From existing bass rack**
1. Load an Instrument Rack preset (`.adg`) you would use in a finished house track
2. Remove or disable extra ambience, modulation, or layers that make the low end blurry
3. Set the rack to one dependable bass role: sub, low-mid, or sub plus quiet mid layer
4. Balance while **Drums** plays, then check against **Pad** and **Stab**
5. Save as **House Bass.adg** on **Bass**; add to template

**Two-chain rack**
1. New MIDI track → Instrument Rack
2. Chain 1: clean sub or sine/triangle-style bass, mono
3. Chain 2: quiet mid bass layer for small speakers; keep it lower than the sub
4. Map one macro to mid-layer level if useful
5. Balance while **Drums** plays, then check against **Pad** and **Stab**
6. Save as **House Bass.adg** on **Bass**; add to template

## House defaults (starting point)

| | Bass |
|---|------|
| Device | Mono synth or Instrument Rack |
| Writing | Piano roll; bass pattern follows the chord roots first, then adds passing notes |
| Octave | Starting point C1–C2; move if it fights the kick |
| Level | Under kick; audible with **Drums**, not louder than the groove |
| Stereo | Mono or near-mono in the low end |
| FX on device | None for space; keep tone shaping simple |

## With the harmony layers

Write bass after the first chord idea exists on **Pad** or **Stab**. Start with root notes, then change rhythm before changing pitch. If harmony feels repetitive in Mode A, use the parent doc's chord rule: change one chord, chord rhythm, or bass pattern.
