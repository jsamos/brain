# Stage 1 — Pad

**Part of:** [Music Production Process](ableton-house-production-workflow.md)  

Build **one** pad sound on **Pad** — a single synth with settings locked in. Save as `House Pad.adg`. One-time setup so Mode A spends time on chord voicings and progression in the piano roll.

## Examples
- **Wavetable** or **Analog** with slow attack
- Split a factory keys Instrument Rack → tune one chain for sustain → save as `House Pad.adg`
- Keep the patch as-is when you would use it on a finished track

## Done when
- [ ] **Pad** track (or your fixed name), preset loaded and ready
- [ ] Sustains 1–2 bars without masking [Stab](ableton-house-stab-template.md)
- [ ] **−6 to −12 dB** vs stab when both play; sits under **Drums** without clipping
- [ ] Track **mute** works independently from **Stab**
- [ ] No reverb or delay on the device (space is Mode C)
- [ ] Preset saved whenever you changed anything from factory defaults
- [ ] One MIDI clip with a sustained chord plays without opening devices

## Build (pick one path)

**Synth pad (default)**
1. New MIDI track → synth (e.g. **Wavetable** or **Analog**): slow attack, long release. For Ableton 12 **Analog**, follow [Analog Pad](ableton-analog-pad-template.md).
2. No device reverb
3. Balance **−6 to −12 dB** below **Stab** while **Drums** plays in the house template (build [Stab](ableton-house-stab-template.md) first if you can)
4. Save as **House Pad.adg**; rename track **Pad**; add to template

**From existing keys rack**
1. Load an Instrument Rack preset (`.adg`)
2. Tune one chain for sustain; remove or disable chains you will not use
3. Save as **House Pad.adg** on **Pad**; add to template

## House defaults (starting point)

| | Pad |
|---|-----|
| Device | Synth |
| Writing | Full chords in piano roll — **progression lives here**; sustain 1–2 bars per chord |
| Octave | Starting point C3–G3; write full chord voicings here |
| Level | −6 to −12 dB vs stab |
| Stereo | Slightly wide; set on **Width**/unison |
| FX on device | None |

## With the other layer

Build after **Stab** when possible so you can set level against it. Intro/break: often pad only, stab muted. Drop/groove: stab + pad together. See **Reference — Stab vs pad** below.

## Reference — Stab vs pad

Two ways to carry the **same harmony** — different length, level, and role.

**Stab** — short, rhythmic chord hit. Fast attack; short decay/release. Job: rhythm and pocket (offbeats, syncopation). Often on in groove/drop; muted in intro or break. See [Stab](ableton-house-stab-template.md).

**Pad** — long, sustained chord tone. Slow attack, long release; harmonic glue behind everything else. Intro/break often pad-only; drop may be stab + pad together.

| | Stab | Pad |
|---|------|-----|
| Length | Milliseconds to ~1 beat | Bars |
| Rhythm | Defines hits | Mostly sustained |
| Level | Louder, up front | Quieter, background |
| Arrangement | Mute for sparse sections | Mute for tighter drops |

Example: Am → F → C → G for 8 bars. Stab hits on beats 2 and 4; pad holds each chord under the drums. Same progression — stab = *when* and punch, pad = *weight* and space.
