# Stage 1 — Stab

**Part of:** [Music Production Process](ableton-house-production-workflow.md)  

Build **one** stab sound on **Stab** — a single sample or synth with settings locked in. Save as `House Stab.adg`. One-time setup so Mode A spends time on stab rhythm in the piano roll.

## Examples
- **Simpler** with a house stab from your sample folder → save as `House Stab.adg`
- Pluck synth (**Wavetable** / **Analog**) with fast decay
- Split a factory keys Instrument Rack → tune one chain for short hits → save as `House Stab.adg`

## Done when
- [ ] **Stab** track (or your fixed name), preset loaded and ready
- [ ] Short, punchy, usable for offbeat or syncopated hits
- [ ] Sits under **Drums** without clipping when soloed
- [ ] No reverb or delay on the device (space is Mode C)
- [ ] Preset saved whenever you changed anything from factory defaults
- [ ] One MIDI clip with a single note plays without opening devices

## Build (pick one path)

**Sample stab (default for house)**
1. New MIDI track → **Simpler** → load a house stab one-shot from your go-to samples
2. **1-Shot** mode; short decay/release; no device reverb
3. Run the [transposable stab big interval test](#transposable-stab-sample-big-interval-test) before saving
4. Balance while **Drums** plays in the house template
5. Save as **House Stab.adg**; rename track **Stab**; add to template

**Synth stab**
1. New MIDI track → synth with pluck-style amp envelope (fast decay)
2. No device reverb; balance while **Drums** plays in the house template
3. Save as **House Stab.adg**; rename track **Stab**; add to template

**From existing keys rack**
1. Load an Instrument Rack preset (`.adg`)
2. Tune one chain for short hits; remove or disable chains you will not use
3. Save as **House Stab.adg** on **Stab**; add to template

## House defaults (starting point)

| | Stab |
|---|------|
| Device | **Simpler** (sample) or pluck synth |
| Writing | Piano roll; 1/8 or 1/16 grid; **same note row** for every hit (e.g. C3) — move hits in time only |
| Octave | Starting point C3–G3; pick one row (e.g. C3) and stay there |
| Level | Reference harmony layer |
| Stereo | Set on synth **Width**/unison/chorus or sample pan |
| FX on device | None |

Keep **3–5 stab samples** in your go-to sample folder (same prep pass as kicks and hats).

## With the other layer

After [Pad](ableton-house-pad-template.md) exists: solo stab + pad together; pad should sit **−6 to −12 dB** below stab. Mute **Stab** independently per section in arrangement.

## Appendix

### Transposable stab sample (big interval test)

Use before saving **House Stab.adg** when the stab is a **Simpler** sample. Tells you if the sample works in any session key (piano roll) or is a chord baked into one file.

1. **Stab** track → **Simpler** with sample loaded → **1-Shot** mode
2. MIDI clip on **Stab** → one note (e.g. **C3**) → press Play; note the sound
3. Replace with a note **far** from the first — **C4** (octave up) or **G2** (fifth down)
4. Press Play again

**Transposable** — clearly higher or lower; still a sensible stab. Big jumps still sound musical → progression on **Pad** (and bass); **Stab** stays on one row for rhythm.

**Chord one-shot** — wrong, thin, or “same chord at wrong speed” (chipmunk or deep mud) → sample is tied to one harmony; use as flavor or stay in that key. Piano roll = **one note per hit**, same row every time; rhythm only; progression on **Pad**.

### Offbeat and syncopated (4-on-the-floor)

Kick on every beat: 1, 2, 3, 4. Stabs and hats add pocket against that pulse.

| | Where it lands |
|---|----------------|
| On the beat | 1, 2, 3, 4 |
| Offbeat | and’s, or 2/4 while kick hammers 1–2–3–4 |
| Syncopated | irregular — between beats, early/late, gaps |

Offbeat/syncopated stabs = bounce against the kick.
